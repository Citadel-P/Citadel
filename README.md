# Citadel

A self-hosted platform for deploying and managing Docker containers, Compose stacks, and Swarm services from one place.

## What you can do

- **Manage your infrastructure** — connect local and remote Docker hosts, inspect resources, and access logs and terminals.
- **Deploy your applications** — run containers and Compose stacks, deploy from Git, and review configuration drift.
- **Build and publish images** — build from Git repositories and push to your registries.
- **Keep workloads running** — monitor resource usage, configure alerts and backups, and automate routine tasks.
- **Control access** — manage users, teams, and permissions, with SSO and activity history.
