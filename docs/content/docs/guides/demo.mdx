## Stable demo

Open [demo.citadelplane.com](https://demo.citadelplane.com/) to explore the stable
release. Sign in with username `demo` and password `citadel-demo-2026`.
Public visitor accounts have **read-only access**.

## Example applications

Both the stable demo and development preview include Nginx, Whoami, and Forgejo
Deployments, two Git Stacks from a shared monorepo, and a Web Editor Stack with
a persistent counter. Browse their configuration, services, and resource details
to see how Citadel organizes applications.

The example Compose monorepositories are available in Forgejo without signing in.
You can browse or clone them:

- [Stable demo monorepository](https://demo.citadelplane.com/forgejo/examples/demo-stacks)
- [Development preview monorepository](https://preview.citadelplane.com/forgejo/examples/demo-stacks)

You can also open the WordPress example on the
[stable demo](https://demo.citadelplane.com/wordpress/) or
[development preview](https://preview.citadelplane.com/wordpress/).

## Backup and restore with RustFS

The stable demo includes a manual backup of the Nginx sample's `example-welcome`
volume, stored in a private RustFS S3-compatible repository.

- Open [RustFS demo backups](https://demo.citadelplane.com/backup-repositories/edit/01a120ed-81a7-7ca3-956f-9e9971d2cd5c)
  to inspect the repository settings.
- Open [Welcome volume to RustFS](https://demo.citadelplane.com/backup-policies/edit/01a120ee-97e4-7003-8baa-056d076efd3f)
  and select **Runs** to see the successful backup and restore history.

The restore created a separate `example-welcome-restored` volume. Its sample page
was verified to match the original byte-for-byte; the running application was
unchanged. Visitors can inspect the records but cannot start backups or restores.

Manual backup and restore are Community capabilities; this example has no schedule
or webhook. RustFS shares the demo host, so this demonstrates the workflow rather
than protection from host loss. See [Backups](/docs/resources/backups) to configure
storage and recovery for your own installation.

## Development preview

The [development preview](https://preview.citadelplane.com/) runs development
releases and upcoming changes. Its separate viewer credentials are username
`demo` and password `demodemo`; public access is also read-only.

Features shown here may not yet be available in the stable release. For your own
installation, follow [install Citadel](/docs/getting-started/install) and use
[documentation matching your version](/docs/reference/releases#documentation-and-api).
