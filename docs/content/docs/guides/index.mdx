These guides cover permissions, shared configuration, integrations, and tasks
that involve several resources. For an individual resource's setup and everyday
operations, start with [Resources](/resources).

| I want to… | Guide |
| --- | --- |
| Find a resource or investigate an operation | [Search and activity](/guides/finding-resources) |
| Change my password or sign out another browser | [Profile and sessions](/guides/profile-and-sessions) |
| Review and apply application updates | [Update applications](/guides/application-updates) |
| Give users and Teams access | [Access control](/guides/access-control) |
| Create credentials for an integration | [Service Accounts](/guides/service-accounts) |
| Supply shared configuration and protected values | [Variables and secrets](/guides/variables-and-secrets) |
| Organize and find resources | [Resource tags](/guides/resource-tags) |
| Manage an application already running | [Adopt existing workloads](/guides/adopting-existing-workloads) |
| Trigger operations from another service | [Webhooks](/guides/webhooks) |
| Use company sign-in | [OIDC providers](/guides/oidc-providers) |
| Protect sign-in with a second factor | [Two-factor authentication](/guides/two-factor-authentication) |

For installing and maintaining Citadel itself, use
[installation](/getting-started/install), [upgrade and rollback](/operations/upgrade-and-rollback),
or [troubleshooting](/operations/troubleshooting).
