---
title: "Choose a task"
description: "Find the steps for common Citadel tasks."
---

After [connecting your first Docker host](/docs/getting-started/first-platform),
choose the task you want to complete. Each guide starts with a short path through
the interface, followed by detailed settings when you need them.

| I want to… | Open in Citadel | Follow this guide |
| --- | --- | --- |
| Run one container | **Deployments** | [Deployments](/docs/guides/deployments) |
| Run a Compose application | **Stacks** | [Manual Stacks](/docs/guides/manual-stacks) |
| Deploy Compose files from Git | **Repositories**, then **Stacks** | [Git Stacks](/docs/guides/git-stacks) |
| Manage an application already running | Its Platform's resources | [Adopt existing workloads](/docs/guides/adopting-existing-workloads) |
| Use a private container registry | **Registries** | [Registries](/docs/guides/registries) |
| Build an image from source | **Repositories**, then **Build Projects** | [Builds](/docs/guides/builds) |
| Save a backup or restore a volume | **Backups** | [Backups](/docs/guides/backups) |
| Set up notifications | **Alert Rules** | [Alert rules](/docs/guides/alert-rules) |
| Give another person access | **Access** | [Access control](/docs/concepts/access-control) |
| Add two-factor authentication | **Profile**, then **Security** | [Two-factor authentication](/docs/guides/two-factor-authentication) |
| Use company sign-in | **OIDC Providers** | [OIDC providers](/docs/guides/oidc-providers) |
| Connect a remote host | **Platforms** | [Agent](/docs/operations/agent) or [Edge Agent](/docs/operations/edge-agent) |
| Manage a Swarm cluster | Its Platform and **Swarm Services** | [Docker Swarm](/docs/concepts/docker-swarm) |
| Run a repeatable script | **Automation** | [Automation actions](/docs/guides/automation-actions) |
| Trigger an operation from another service | The resource's webhook settings | [Webhooks](/docs/guides/webhooks) |

Manual operations are available in Community. Some schedules, automatic actions,
and advanced controls require a paid capability; each guide explains its
requirements. See [editions](/docs/overview/licensing) for the complete comparison.
