title: "Guides"

These guides cover permissions, shared configuration, integrations, and tasks
that involve several resources. For an individual resource's setup and everyday
operations, start with [Resources](/docs/resources).

| I want to… | Guide |
| --- | --- |
| Find a resource or investigate an operation | [Search and activity](/docs/guides/finding-resources) |
| Change my password or sign out another browser | [Profile and sessions](/docs/guides/profile-and-sessions) |
| Review and apply application updates | [Update applications](/docs/guides/application-updates) |
| Give users and Teams access | [Access control](/docs/guides/access-control) |
| Create credentials for an integration | [Service Accounts](/docs/guides/service-accounts) |
| Supply shared configuration and protected values | [Variables and secrets](/docs/guides/variables-and-secrets) |
| Organize and find resources | [Resource tags](/docs/guides/resource-tags) |
| Manage an application already running | [Adopt existing workloads](/docs/guides/adopting-existing-workloads) |
| Trigger operations from another service | [Webhooks](/docs/guides/webhooks) |
| Use company sign-in | [OIDC providers](/docs/guides/oidc-providers) |
| Protect sign-in with a second factor | [Two-factor authentication](/docs/guides/two-factor-authentication) |

For installing and maintaining Citadel itself, use
[installation](/docs/getting-started/install), [upgrade and rollback](/docs/operations/upgrade-and-rollback),
or [troubleshooting](/docs/operations/troubleshooting).
