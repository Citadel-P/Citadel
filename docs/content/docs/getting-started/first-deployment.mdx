---
title: "Run your first application"
description: "Create a Deployment and open a simple website."
---

A **Deployment** runs one container from an image. You need an online Docker
Standalone Platform; connect one using
[connect a Docker host](/docs/getting-started/first-platform).

## Create and deploy

1. Open **Deployments** and select **Add Deployment**.
2. Name it `hello-web` and select your Platform.
3. Choose **External** under **Image Source**, select **Docker Hub**, and enter `nginx:alpine`.
4. Under **Networks**, select `bridge`.
5. In the **Ports** editor, enter `8080:80/tcp` to publish host port `8080` to container port `80`. Choose another host port if `8080` is in use.
6. Select **Save**, then **Deploy**. Enter `hello-web` in the confirmation dialog, select **Deploy**, and wait for the operation to finish.
7. Open `http://YOUR-DOCKER-HOST:8080`. For a local host, use [http://localhost:8080](http://localhost:8080).

**Success looks like:** the container is running and the browser shows the
Nginx welcome page. The host firewall determines who can reach port `8080`.

## View logs or change the application

Open the Deployment to view its container, logs, and configuration. Saving a
change updates Citadel's settings. Select **Deploy** or **Redeploy** to send the
reviewed configuration to Docker; this can recreate the container.

If deployment fails, read the error in the operation panel before retrying.
A port already in use or an image pull failure are common causes.

For persistent data, image updates, and existing containers, see the
[Deployment guide](/docs/guides/deployments). Use a
[Stack](/docs/getting-started/first-stack) for an application with several services.
