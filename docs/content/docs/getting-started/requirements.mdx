## Host

The provided installation uses Docker Compose on a Linux Docker host. The host
must be able to pull the released Citadel and PostgreSQL images and must provide
persistent storage for both named volumes.

The Core container mounts `/var/run/docker.sock` to manage its local Docker
platform. Docker socket access is equivalent to administrative host access;
do not expose the socket over an unauthenticated network endpoint.

## Network and identity

Prepare:

- a stable HTTPS hostname for browser and API access;
- a reverse proxy, or a PEM certificate and key for direct TLS;
- a strong PostgreSQL password;
- firewall rules for the traffic listed in [network ports](/docs/reference/network-ports);
- DNS and a public gRPC address when Edge Agents are used.

## Compatibility

The exact Docker, browser, architecture, Core, and Agent versions supported by
a release belong to that release's notes. Do not infer support from an upstream
project's latest version. Citadel Core and Agent should use matching product
release lines unless the release notes explicitly state otherwise.

Citadel has not published a stable v1 tag yet. Until that tag exists, source
builds are development installations rather than supported production releases.
