---
title: "Connect a Docker host"
description: "Choose a connection and see your Docker resources in Citadel."
---

A **Platform** is a Docker host or Swarm cluster that Citadel manages. Connecting
it lets you see its existing resources; it does not deploy or replace them.

## Choose a connection

| Where is Docker running? | Connector | What you need |
| --- | --- | --- |
| On the same host as Citadel | **Local** | The Docker socket mounted into Citadel; the supplied Compose setup includes it |
| On another host that Citadel can reach | **Agent** | Install the generated Agent command and allow Citadel to reach its Agent port |
| Behind NAT or a firewall that blocks inbound access | **Edge Agent** | Run the generated enrollment command; the host connects out to Citadel |

Use one Platform per Docker engine. A Citadel installation can have only one
Local Platform. For Swarm, connect an existing **manager**; adding a Platform
does not create a Swarm cluster.

## Connect local Docker

1. Sign in as an administrator.
2. Open **Platforms** and select **Add Platform**.
3. Select **Docker Standalone** and **Local**.
4. Enter a name such as `local-docker` and select **Save**. Use 3 to 64 letters, numbers, hyphens, or underscores.
5. Open the Platform after it comes online. You should see the containers already on this host.

For a remote machine, follow [Agent setup](/docs/operations/agent) or
[Edge Agent setup](/docs/operations/edge-agent). For a Swarm cluster, use the
[Swarm guide](/docs/resources/platforms/docker-swarm).

![Example Platforms page showing connected Docker and Swarm hosts](/screenshots/platforms.png)

The names in this example are demonstration hosts. Your own Platform should
appear here after it connects.

You can now [read container logs or open a terminal](/docs/resources/docker/containers),
[browse volume contents](/docs/resources/docker/volumes), or
[deploy your first application](/docs/getting-started/first-deployment).

## If it stays offline

Check that Docker is running and that Citadel can reach the selected socket or
Agent. An Edge Platform stays offline until its Agent enrolls and connects.
See [troubleshooting](/docs/operations/troubleshooting) before adding a duplicate
Platform.
