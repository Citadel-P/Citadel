---
title: "Getting started"
description: "Run Citadel and deploy your first container."
---

The fastest way to learn Citadel is to run it on a machine that already has
Docker:

1. [Start Citadel locally](/docs/getting-started/quick-start).
2. Create your administrator account in the browser.
3. Connect the local Docker engine.
4. Deploy `nginx:alpine` from the built-in Docker Hub registry.

The quick-start guide walks through all four steps on one page. When you are
ready for a permanent installation, continue with the
[production installation](/docs/getting-started/install).
