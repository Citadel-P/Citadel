Explore Citadel's resources, their configuration options, and supported
operations. Each reference covers the resource's role and how to manage it
throughout its lifecycle.

| Resource | Use it to |
| --- | --- |
| [Platforms](/resources/platforms) | Connect Docker Standalone hosts and Swarm clusters |
| [Containers](/resources/docker/containers) | Read logs, open terminals, and control container state |
| [Images](/resources/docker/images) | Pull and inspect images stored on a Docker host |
| [Networks](/resources/docker/networks) | Connect workloads through Docker networks |
| [Volumes](/resources/docker/volumes) | Manage persistent storage and browse or download files |
| [Deployments](/resources/deployments) | Run individual containers on Docker Standalone |
| [Stacks](/resources/stacks) | Deploy Compose applications from the Web Editor or Git |
| [Swarm Services](/resources/swarm-services) | Manage individual Services on a Swarm cluster |
| [Build Projects](/resources/builds) | Build images from Git and publish them to a Registry |
| [Build Pools](/resources/build-pools) | Connect dedicated builders and monitor their availability |
| [Registries](/resources/registries) | Configure image pull and push access |
| [Git Repositories](/resources/git-repositories) | Connect source repositories and Git credentials |
| [Backups](/resources/backups) | Configure repositories and policies, run backups, and restore data |
| [Scripts](/resources/scripts) | Save and run repeatable scripts |
| [Alert Rules](/resources/alert-rules) | Define alert conditions and notification delivery |

For permissions, shared variables and secrets, tags, authentication, webhooks,
or adopting existing applications, see [Guides](/guides).

## Resource descriptions

Descriptions support basic Markdown: `**bold**`, `*italic*`,
`[link text](https://example.com)`, inline code, bullet and numbered lists,
and `> quotes`. Use the small help icon inside the bottom-right corner of the
description field to open the formatting guide. Edit the Markdown text directly;
saved descriptions appear formatted beneath the resource name.

In the resource header, use the pencil to edit, Ctrl+Enter (Cmd+Enter on macOS)
to save, and Escape to discard your draft. Description links open in a new tab.
Existing descriptions are interpreted as Markdown when displayed; their stored
text is unchanged. To display formatting characters literally, escape them with
a backslash, for example `\*literal asterisks\*`. Images and HTML formatting
are not supported.
