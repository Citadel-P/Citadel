title: "Resources"
description: "Learn what each Citadel resource does and how to configure and operate it."
---

Explore Citadel's resources, their configuration options, and supported
operations. Each reference covers the resource's role and how to manage it
throughout its lifecycle.

| Resource | Use it to |
| --- | --- |
| [Platforms](/docs/resources/platforms) | Connect Docker Standalone hosts and Swarm clusters |
| [Containers](/docs/resources/docker/containers) | Read logs, open terminals, and control container state |
| [Images](/docs/resources/docker/images) | Pull and inspect images stored on a Docker host |
| [Networks](/docs/resources/docker/networks) | Connect workloads through Docker networks |
| [Volumes](/docs/resources/docker/volumes) | Manage persistent storage and browse or download files |
| [Deployments](/docs/resources/deployments) | Run individual containers on Docker Standalone |
| [Stacks](/docs/resources/stacks) | Deploy Compose applications from the Web Editor or Git |
| [Swarm Services](/docs/resources/swarm-services) | Manage individual Services on a Swarm cluster |
| [Build Projects](/docs/resources/builds) | Build images from Git and publish them to a Registry |
| [Build Pools](/docs/resources/build-pools) | Connect dedicated builders and monitor their availability |
| [Registries](/docs/resources/registries) | Configure image pull and push access |
| [Git Repositories](/docs/resources/git-repositories) | Connect source repositories and Git credentials |
| [Backups](/docs/resources/backups) | Configure repositories and policies, run backups, and restore data |
| [Automation](/docs/resources/automation-actions) | Save and run repeatable automation actions |
| [Alert Rules](/docs/resources/alert-rules) | Define alert conditions and notification delivery |

For permissions, shared variables and secrets, tags, authentication, webhooks,
or adopting existing applications, see [Guides](/docs/guides).

New to Citadel? Start with the [quick start](/docs/getting-started/quick-start).
